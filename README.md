# 🍳 AI-Шеф

Умный помощник, который смотрит на фото твоего холодильника и придумывает рецепт из найденных продуктов!

## ✨ Возможности

- 📸 **Распознавание продуктов** — загрузи фото, и нейросеть определит, что у тебя есть
- 👨‍🍳 **Генерация рецептов** — персональный рецепт под твои продукты
- 🌍 **Выбор кухни** — итальянская, азиатская, грузинская и другие
- 🥗 **Фильтры** — вегетарианское, быстрое, диетическое
- 🎨 **Фото блюда** — визуализация готового результата
- 📜 **История рецептов** — все созданные блюда сохраняются

## 🛠️ Технологии

- **Python** — язык программирования
- **Streamlit** — веб-интерфейс
- **Google Gemini API** — мультимодальная нейросеть
- **Pillow** — обработка изображений

## 🚀 Быстрый старт

### 1. Клонируй репозиторий

```bash
git clone https://github.com/Anchelotti019/ai-chef.git
cd ai-chef
``` 

### 2. Установи зависимости

```bash
pip install -r requirements.txt
```

### 3. Настрой API ключ

Создай файл .env в корне проекта и добавь свой ключ:
GEMINI_API_KEY=твой_ключ
Получить ключ можно на [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

### 4. Запусти прилжение

```bash
streamlit run app.py
```
Открой браузер по адресу 'http://localhost:8501'
